# 🚀 Полёт до звезды Проксима Центавра

Релятивистский расчёт и интерактивный симулятор полёта космического корабля к ближайшей звезде — Проксиме Центавра (4.2465 св. года).

▶️ **[Открыть симулятор в браузере](https://eremin.online/flight-to-proxima-centauri/)**

Учитывается полная СТО (специальная теория относительности): время по часам наблюдателя на Земле и собственное время экипажа на борту (замедление времени / дилатация).

## Профиль миссии

Разгон с постоянным собственным ускорением `a` до крейсерской скорости `v_c` → равномерный полёт → симметричное торможение до полной остановки у цели.

Если крейсерская скорость недостижима на половине пути, расчёт автоматически переключается на режим **брахистохроны** (разгон ровно до середины дистанции, затем торможение) — это предельно быстрый профиль для заданного ускорения.

## Результаты (ускорение 1g = 9.80665 м/с²)

| v крейсерская | Режим | Время по Земле | Время экипажа | γ_max | Замедление времени |
|---|---|---|---|---|---|
| 0.10c | крейсер | 42.562 лет | 42.349 лет | 1.005 | 1.01× |
| 0.20c | крейсер | 21.428 лет | 21.001 лет | 1.021 | 1.02× |
| 0.50c | крейсер | 9.012 лет | 7.900 лет | 1.155 | 1.14× |
| 0.80c | крейсер | 6.277 лет | 4.345 лет | 1.667 | 1.44× |
| 0.99c¹ | брахистохрона | 5.873 лет | 3.542 лет | 3.192 | 1.66× |

¹ При 1g на дистанции 4.25 св. года скорость 0.99c физически недостижима к середине пути — расчёт автоматически переходит в режим «разгон-торможение» без крейсерской фазы. Максимальная фактически достигнутая скорость ≈ 0.949c.

**Главный вывод:** предел при ускорении 1g — около 5.9 лет по Земле / 3.5 года для экипажа. Быстрее при комфортном земном ускорении на этой дистанции не получится.

## Формулы

Релятивистское равноускоренное (гиперболическое) движение:

```
β = v_c / c                          # доля скорости света
γ = 1 / √(1 − β²)                     # Лоренц-фактор
x₁  = (c²/a)·(γ − 1)                  # дистанция фазы разгона
t₁  = γ·v_c / a                       # время разгона по Земле
τ₁  = (c/a)·artanh(β)                 # собственное время разгона
x₂  = D − 2·x₁                        # крейсерская дистанция
T   = 2·t₁ + x₂/v_c                   # полное время по Земле
τ   = 2·τ₁ + x₂/(γ·v_c)               # полное собственное время экипажа
```

Режим брахистохроны (без крейсера), разгон до середины пути `D/2`:

```
γ_mid = 1 + a·(D/2)/c²
β_mid = √(1 − 1/γ_mid²)
T   = 2·γ_mid·(β_mid·c)/a
τ   = 2·(c/a)·artanh(β_mid)
```

## Файлы

- **`proxima_flight.py`** — параметрический Python-калькулятор. Чтобы изменить ускорение, расстояние или набор скоростей, отредактируйте константы `DISTANCE_LY`, `ACCEL` и список `cruise_speeds`, затем запустите:

  ```bash
  python3 proxima_flight.py
  ```

- **`index.html`** — интерактивный самодостаточный симулятор (без внешних зависимостей, вся физика на JavaScript, проверена на совпадение с Python-расчётом). Просто откройте файл в браузере.

  Возможности:
  - вид со стороны (система Земли) — звёздное поле с warp-эффектом, факел двигателя (разгон/торможение);
  - вид из кабины (глазами экипажа) — аберрация света, эффект Доплера, сокращение длины;
  - двое часов с разным ходом (Земля / экипаж) — визуализация замедления времени;
  - слайдер крейсерской скорости, кнопки ускорения (0.1g / 1g / 3g), управление скоростью воспроизведения;
  - таблица итогов миссии и сравнение сценариев при разных крейсерских скоростях.
